# Demo QR Tokens

The local demo scanner supports manual token entry for desktop testing.

Use these seeded values:

```text
IPOH-KLT-001
IPOH-CONCUBINE-001
IPOH-PLATFORM-001
IPOH-KONGHENG-001
IPOH-INACTIVE-001
```

The MVP validates token activity, duplicate scans, associated location, and points from application seed data. Point values are not encoded in the token.
